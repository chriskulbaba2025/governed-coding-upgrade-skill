# Branding Assets

- `logo.svg` — primary README/header mark.
- `icon.svg` / `icon.png` — square repository/project icon.
- `social-card.svg` / `social-card.png` — 1280×640 social/Open Graph artwork.

The assets use a dark slate and teal visual system to represent control, branching, verification, and governed release.

For GitHub's social preview, upload `social-card.png` in the repository settings after publication if a custom preview is desired.
