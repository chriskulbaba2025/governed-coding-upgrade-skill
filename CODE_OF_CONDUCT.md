# Code of Conduct

Project collaboration is expected to remain professional, evidence-based, and focused on the work.

- Critique implementations, requirements, and proof rather than people.
- Report uncertainty and failed evidence directly.
- Do not misrepresent incomplete work as complete.
- Do not bypass repository security, privacy, audit, or release controls for convenience.
- Keep confidential repository information confidential.

Repository owners may restrict participation when these standards are not followed.
