# Governed Change Final Report

**Skill version:** 2.1.0

Record: starting SHA, final SHA, branch, PR, change class, release intent, exact changed files, production-spine result, contract-map result, acceptance-freeze result, false-PASS scan result, terminal-path result, full-system readiness result, checklist evidence, verification commands, scope result, exact-head CI, independent audit, repository state, and release authorization.

Report `CHANGE RESULT` separately from `SYSTEM READINESS`. Do not claim `RELEASE READY` while any mandatory proof or authorization is open or failed.
